01 // USERNAME OSINT

닉네임을 검색엔진 및 공개 플랫폼 검색으로 확인합니다. 결과를 자동으로 동일 인물이라고 판단하지 않습니다.

닉네임을 입력하세요.

이 페이지는 사이트별 계정 존재 여부를 확정하지 않습니다. 각 공개 검색 결과를 직접 확인해야 합니다.

02 // EMAIL CHECK

이메일 형식을 확인하고, 도메인의 MX 레코드를 실제 조회합니다. 이메일 전체 주소는 외부 API로 전송하지 않습니다.

이메일을 입력하세요.
Have I Been Pwned — 알려진 유출 여부 직접 확인 ↗

유출 확인 사이트는 별도 서비스입니다. 이 페이지가 유출 여부를 임의로 판정하지 않습니다.

03 // DNS RECON

Google Public DNS API로 DNS 레코드를 실제 조회합니다.

도메인을 입력하세요.

04 // IP INTELLIGENCE

ipwho.is API를 통해 공개 IP 정보와 대략적인 지역 정보를 조회합니다. 서비스가 막히면 오류를 표시합니다.

IP 주소를 입력하세요.

IP 위치 정보는 부정확할 수 있으며 VPN·모바일망·프록시에서는 실제 이용자 위치와 다를 수 있습니다. 다른 사람의 IP를 알아내기 위한 추적 링크 기능은 제공하지 않습니다.

05 // FILE ANALYZER

파일은 브라우저에서 로컬 분석합니다. 파일을 업로드하거나 외부로 보내지 않습니다.

파일을 선택하세요.

SHA-256은 파일 식별용 해시입니다. 해시만으로 파일이 악성인지 확정할 수 없습니다. 실행하지 말고 출처가 불분명한 파일은 열지 마세요.

06 // IMAGE SOURCE

이미지 파일의 기본 정보와 해시를 확인하고, 역이미지 검색 서비스를 엽니다. 자동으로 이미지 출처를 판정하지 않습니다.

이미지를 선택하세요.
Google Lens 열기 ↗TinEye 역이미지 검색 열기 ↗

검색 서비스에 이미지를 직접 넣어야 할 수 있습니다. 사진 속 사람의 신원을 자동으로 식별하지 않습니다.

07 // WEBSITE SECURITY

URL 형식을 확인하고 HTTPS 및 공개 DNS를 확인합니다. 보안 헤더는 브라우저 CORS 정책 때문에 이 페이지에서 직접 읽지 못할 수 있습니다.

URL을 입력하세요.
SecurityHeaders — 서버 보안 헤더 검사 ↗SSL Labs — TLS 설정 검사 ↗

외부 검사 링크는 해당 서비스에서 직접 실행됩니다. 이 페이지는 검사를 실행한 척하거나 외부 결과를 만들어내지 않습니다.

08 // LIVE MONITOR

현재 페이지에 5초 간격으로 요청해 실제 응답 시간을 측정합니다.

측정 전

이 모듈은 현재 페이지만 측정합니다. 외부 도메인 모니터링은 CORS와 서비스 정책에 따라 제한됩니다.

Level 0 접속하기
